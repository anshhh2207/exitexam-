# MERN Task Management App (Session-based Auth)

Backend: `backend`
Frontend: `frontend`

Quick start (requires Node.js and MongoDB):

1. Backend

```
cd backend
cp .env.example .env
# edit .env to set MONGODB url and SESSION_SECRET
npm install
npm run dev
```

2. Frontend

```
cd frontend
npm install
npm run dev
```

Open the frontend at http://localhost:5173
